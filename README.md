Student Management System
A console-based Student Management System developed using Core Java.

Features

- Add a new student
- View all students
- Search student by ID
- Update student details
- Delete a student
- Calculate student grades
- Validate age and marks
- Prevent duplicate student IDs
- Save and load student records using file handling


Technologies Used

- Java
- OOP (Classes and Objects)
- ArrayList and Collections
- Exception Handling
- File Handling
- BufferedReader and BufferedWriter


Project Structure

- `Main.java` — Menu and user interaction
- `Student.java` — Student details and grade calculation
- `StudentService.java` — Student management operations
- `FileHandler.java` — Saving and loading student records
- `students.txt` — Local data storage file


How to Run

1. Open the project in your Java IDE.
2. Compile the Java files.
3. Run `Main.java`.
4. Follow the menu options in the console.


Learning Outcomes

This project helped me practice Core Java, OOP, collections, validation, and persistent file storage.
